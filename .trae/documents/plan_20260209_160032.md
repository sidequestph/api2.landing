# Project: SideQuest Fortress Implementation Plan

We will transform the current Lumen application into a high-security Licensing API.

## 1. Foundation & Dependencies
We need to equip the application with Redis for rate limiting and ensure Sodium is available for crypto.
*   **Install Dependencies**: `illuminate/redis` and `predis/predis` (for IP blacklisting/throttling).
*   **Configuration**: Enable Redis in `bootstrap/app.php` and `.env`.

## 2. Database Schema (The Vault)
We will create a robust, normalized schema.
*   **Migrations**:
    *   `create_licenses_table`: Stores the master keys (`SQ-{RANDOM}`).
    *   `create_activations_table`: Stores domain bindings (Foreign Key to `licenses`).
    *   `create_audit_logs_table`: Stores security events (brute force attempts, actions).
*   **Models**: `License`, `Activation`, `AuditLog` with proper relationships.

## 3. Security Layer (The "Fortress")
This is the core of the request.
*   **Middleware (`FortressSecurityMiddleware`)**:
    *   **User-Agent Gate**: Block anything not matching `SideQuest-Hub/1.0`.
    *   **Replay Attack Protection**: Verify `request_timestamp` is within 5 minutes.
    *   **Format Enforcer**: Reject non-JSON requests.
*   **Crypto Service**:
    *   Implement **Ed25519 Signing** for API responses using `sodium_crypto_sign_detached`.
    *   Store Private Key in `.env` (`SIDEQUEST_SIGNING_KEY`).

## 4. API Logic & Endpoints
*   **Controller**: `LicenseController`
    *   `POST /activate`: Atomic transaction to bind domain. Checks limits. Returns signed payload.
    *   `POST /check`: Heartbeat. Updates `last_checkin_at`. Triggers "Remote Wipe" if domain mismatches.
    *   `POST /deactivate`: Unbinds the license.
*   **Routes**: Group under `/v1/license` with `throttle:60,1` and `fortress` middleware.

## 5. Defense Mechanisms
*   **IP Blacklisting**: Implement a fail-counter in Redis. If >10 failures/min, ban IP for 24h.
*   **Audit Logging**: Log every significant action (especially failures) to `audit_logs`.

## Execution Steps
1.  Install Redis dependencies.
2.  Create and run Database Migrations.
3.  Implement Models (`License`, `Activation`, `AuditLog`).
4.  Create `FortressSecurityMiddleware`.
5.  Implement `LicenseController` with Ed25519 signing.
6.  Register Routes and Middleware.
